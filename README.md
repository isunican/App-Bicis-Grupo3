Este repositorio contiene el código inicial para el Proyecto Integrado 2026

La información relativa al Proyecto Integrado, y las asignaturas que lo componen, se puede encontrar en la [Wiki](https://github.com/isunican/docsProyectoIntegrado/wiki).

La aplicación inicial incluye funcionalidad básica para descargar y mostrar información sobre redes de bicicletas compartidas, utilizando la [API CityBikes](https://api.citybik.es/v2/).

Información sobre este servicio REST puede encontrarse en [este documento](servicio-bicicletas.md).

La aplicación utiliza el patrón Model-View-Presenter. Información detallada sobre la arquitectura de la aplicación y el modelo de dominio puede consultarse [aquí](Docs/Models/README.md)
