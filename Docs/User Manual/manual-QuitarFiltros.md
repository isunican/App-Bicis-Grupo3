
# Manual de usuario - Quitar filtros

## Historia de usuario 532317

Esta funcionalidad permite eliminar todos los filtros aplicados a las estaciones de bicicletas y volver a visualizar la lista completa de estaciones de la ciudad.

## Procedimiento

1. Acceder a la pantalla de estaciones de la ciudad.
2. Aplicar uno o varios filtros sobre las estaciones.
3. Pulsar el botón "Quitar filtros".
4. La aplicación muestra nuevamente todas las estaciones, sin los filtros anteriores.

## Resultado esperado

Al quitar los filtros, se recupera la lista completa de estaciones.

Si no hay filtros aplicados, la lista permanece sin cambios.

## Gestión de errores

Si la operación falla, la aplicación muestra un mensaje indicando que no se han podido quitar los filtros.

En ese caso, deben mantenerse los filtros y las estaciones que se estaban mostrando.

## Observaciones

La funcionalidad está pendiente de validación completa mediante las pruebas de aceptación una vez integrada la pantalla de estaciones.
